# 第一题:结构化信息提取与展示

## 背景

宏观研究员每日需要阅读大量市场资讯(央行讲话、PMI 数据、美联储会议纪要等),需要将这些非结构化文本转化为结构化的"市场因子卡片",便于后续时间序列分析和策略调用。

## 题目要求

请编写一个函数 `extract_market_factors(text: str) -> dict`,将以下示例文本解析为结构化的 JSON 输出:

### 输入示例

> 2026年4月30日,美联储维持基准利率在 4.25%-4.50% 区间不变,鲍威尔在会后记者会上表示"通胀回落进程有所停滞,我们将保持耐心"。同日公布的美国 4 月非农就业新增 17.5 万人,低于市场预期的 24 万人,失业率小幅上升至 4.2%。中国央行宣布自 5 月 15 日起下调存款准备金率 0.5 个百分点,释放长期流动性约 1 万亿元。10 年期美债收益率当日下跌 12bp 至 4.28%。

### 输出要求 (JSON Schema)

```json
{
  "date": "2026-04-30",
  "factors": [
    {
      "factor_id": "FED_RATE_20260430",
      "category": "货币政策",
      "entity": "美联储",
      "event": "维持利率不变",
      "details": {"rate_range": "4.25%-4.50%", "stance": "鹰派偏谨慎"},
      "market_impact": "中性偏鹰",
      "sentiment_score": -0.3,
      "source_quote": "通胀回落进程有所停滞,我们将保持耐心"
    }
  ],
  "cross_asset_summary": {
    "rates": {"10Y Treasury": {"change_bp": -12, "close": 4.28}},
    "fx": {},
    "equity": {}
  }
}
```

## 作答要求

- 提供完整可运行代码(含 prompt 设计和解析逻辑)
- 说明:你是如何设计 prompt 来确保 JSON 格式输出的?正向约束和负向约束分别用了哪些?
- 简单说明你本次笔试使用的大模型或 AI 工具,以及使用经验。
